# 대시보드 테스트 퍼소나와 시나리오 설계

대시보드를 포함한 프론트엔드 화면을 실제 사용자 흐름처럼 검증하기 위한 테스트 퍼소나 문서입니다.
계급별 월급, 계좌 연결 여부, 소비·투자 행동, 이벤트와 미션 상태를 조합해 빈 화면부터
수익·손실·초과 상태까지 자연스럽게 확인하는 것을 목적으로 합니다.

> 현재 퍼소나 전환은 대시보드 화면에만 구현되어 있습니다. 다른 화면은 기존 데이터를 사용합니다.

## 공통 기준

- 기준 시각: `2026-08-06T20:00:00+09:00`
- 이병 월급: 750,000원
- 일병 월급: 900,000원
- 상병 월급: 1,200,000원
- 병장 월급: 1,500,000원
- 날짜와 월별 합산은 Asia/Seoul 기준
- 투자 변동은 현재 월에 발생한 증권계좌 변동만 합산
- 수입은 현재 월의 `INCOME` 거래만 합산
- 지출은 현재 월의 `EXPENSE` 거래만 합산

## 퍼소나별 대시보드 전환 방법

### 테스트 URL

개발 환경에서 다음 쿼리로 대시보드 전체 상태를 선택합니다.

```text
/home?persona=private-newcomer
/home?persona=pfc-safe-px
/home?persona=corporal-balanced-profit
/home?persona=sergeant-aggressive-loss
```

`persona`는 사용자 전체 상태를 선택하고, 기존 `scenario`는 특정 컴포넌트 상태만 강제로
확인하는 용도로 분리합니다.

```text
/home?persona=corporal-balanced-profit&scenario=no-investment-account
```

위 예시는 상병 퍼소나의 전체 데이터는 유지하면서 투자 블록만 증권계좌 미연결 상태로 덮어씁니다.

적용 우선순위는 다음과 같이 설계합니다.

```text
공통 기본값 → 선택한 persona 데이터 → 선택한 scenario 데이터
```

### 개발용 퍼소나 선택기 확장안

URL을 매번 직접 수정하지 않도록 추후 개발 환경에서만 표시되는 작은 선택기를 둘 수 있습니다.

- 노출 조건: `import.meta.env.DEV`
- 위치: 대시보드 우측 상단 또는 별도의 개발 도구 패널
- 선택 항목: 4개 퍼소나와 컴포넌트 시나리오
- 선택 결과: URL query와 `localStorage`에 저장
- 운영 빌드: 자동 제거

URL이 있으면 URL 값을 우선하고, URL이 없으면 마지막으로 선택한 `localStorage` 값을 사용합니다.
아무 값도 없으면 기존 기본 대시보드 데이터를 사용합니다.

## 상세 목데이터 확인 방법

화면에서 선택된 데이터를 바로 확인할 수 있도록 개발 환경에 아래 기능을 함께 두는 방법을 권장합니다.

### 1. 데이터 미리보기 패널

개발용 선택기에 `현재 목데이터 보기` 버튼을 추가합니다. 버튼을 누르면 현재 화면에 실제 전달된
데이터를 JSON 형태로 확인합니다.

표시할 영역:

- 사용자와 군 프로필
- 대시보드 응답
- 연결 계좌
- 현재 월 거래내역
- 투자 변동내역
- 예정 이벤트
- 오늘의 미션과 데일리 미션

### 2. 데이터 출처 표시

각 JSON 묶음에 API 정보를 함께 표시합니다.

| 데이터 | 예정 API |
| --- | --- |
| 사용자·군 프로필 | `GET /api/v1/users/me` |
| 대시보드 요약 | `GET /api/v1/dashboard` |
| 연결 계좌 | `GET /api/v1/accounts/{userId}` |
| 현재 월 거래내역 | `GET /api/v1/transactions?startDate=&endDate=` |
| 투자 변동내역 | 백엔드 API 확인 필요 |
| 미션 | `GET /api/v1/missions/today` |
| 이벤트 | `DashboardResponse.upcomingEvents`, CRUD API 확인 필요 |
| 자산 예측 | `GET /api/v1/cashflow?months=` |

### 3. 콘솔 접근

필요하면 개발 환경에서 현재 조합 결과를 아래처럼 노출할 수 있습니다.

```js
window.__JAEDAERO_DASHBOARD_MOCK__
```

화면과 JSON 패널에서 이상이 있을 때 브라우저 콘솔에서 같은 데이터를 빠르게 비교할 수 있습니다.
운영 환경에는 이 값을 노출하지 않습니다.

## 현재 구현 구조

```text
src/features/dashboard/mocks/
├── dashboard.mock.js
├── dashboard.personas.js
```

- `dashboard.personas.js`: 사용자 전체 맥락을 가진 4명의 대시보드 데이터
- `dashboard.mock.js`: 기본값, 퍼소나, 투자 시나리오를 조합하고 기존 export 제공
- `DashboardView.vue`: URL의 `persona`, `scenario` query를 읽어 최종 데이터를 선택
